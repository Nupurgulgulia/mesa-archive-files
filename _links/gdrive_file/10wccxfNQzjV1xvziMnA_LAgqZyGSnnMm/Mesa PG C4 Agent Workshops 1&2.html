Before we start

How to read anything an AI writes

Three labels. You will use them in every step of both workshops. Learn them now and the rest of the day is easy.

Verified  A named source exists, it has a date, and you opened it.
Asserted  Sounds right, no source. Treat it as a guess, never as a fact.
Fabricated  Stated as fact, no source exists anywhere. This is the one that loses deals.

The problem with a fabricated claim is that it looks identical to a real one. A made-up funding round reads exactly like a real funding round. Nothing in the output warns you.

Four rules for the day

  1. One job per prompt. That is why today is five small steps instead of one big one.
  2. Decide the output shape first. Every prompt today tells the AI exactly what format to return.
  3. Something else has to grade it. Asking the same chat "is this good?" always gets a yes.
  4. You own every line. Nobody has ever survived a deal review by saying the agent wrote it.

Why yes and no, instead of a score out of 10

If the grader says "quality: 7/10, fairly thorough", you have not built a grader. You have built a second opinion that makes things up just as confidently as the first one did. You can check a YES in five seconds. You cannot check a 7. A grade you cannot check is not a grade.

Practice first — spot the bad claims

Six claims about Meridian Castings, a company we invented. It is not real. We made it up so we could plant mistakes in it on purpose, which we would not do to a real business. Three claims are unusable. Click the ones you would refuse to put in front of a buyer.

Three failure types. They never change.

Made up — no source exists. Out of date — true once, not now. Joined without evidence — two real facts, one invented link between them. Learn these three and you can check any AI output in any job.

Prompts, saved prompts, and skill files

You have probably been wondering whether to save all this somewhere. Here is the honest answer.

Today you pasted prompts by hand and copied output between them. That worked. Here is what changes if you save them, and what does not.

What it isLives whereUse it when
A promptText you paste into one chatNowhere. It dies with the chat.You are still working out what you want. This is where you are today.
Project instructionsA prompt that applies to every chat in one ProjectSaved in the Project. One per Project.Something is true for all five steps, like "always cite a source".
A skill fileA named prompt saved as its own fileA folder. As many as you like.You do the same job repeatedly and want to call it by name.
The part that surprises people

The text does not change. A skill file is the same words you pasted today, in a file, with a name. There is no special syntax to learn and no code to write. The only thing that changes is where it lives and who calls it.

What that looks like as a folder

the same prompts, saved

    our-product.md          what we sell
    target-account.md       who we are researching
  skills/
    00-icp.md               the Step 0 prompt, unchanged
    01-shift.md             the Step 1 prompt, unchanged
    02-account.md
    03-role.md

    grade-research.md       the grading prompt
  outputs/
    personalization-pack.md

No code. Eight text files and three folders.

The one rule that makes it work

No skill file may contain a company name. Every fact about what you sell and who you are researching goes in context/. If you typed "Procol" into 02-account.md, then the day you point it at a different product it will quietly keep researching procurement software. It will not throw an error. It will just be wrong.

Do you have to do this?

No. Copy-paste works fine for one account. Saving to files starts paying off somewhere around your twentieth account, and only once the prompts have stopped changing. Saving a prompt you are still fixing is the wrong order.

What you actually built today

When you pasted Step 2's output into Step 3, you were the thing running the chain. Automation would replace you, not the chain.

And there is a cost. Running it by hand, you saw all five outputs and caught the bad one. Automated, you would see only the final pack, with a made-up claim from Step 1 quietly repeated and built on three times over. It would come out sounding more confident than the research deserved.

So automation does not remove the human. It moves them from checking five outputs to deciding what is allowed to pass. The grading prompt you wrote today is what that check is made of.

The rule for both

Every sentence must come from a named field in your pack. If it comes from nowhere, it is filler and it goes. This is stricter than it sounds. Most cold emails are around 70% filler, and the person writing them cannot see it until they are forced to trace each sentence back.
